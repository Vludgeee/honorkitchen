# Заметки для портфолио / куратор (колледж)

## Проект

- **Название в билде:** MyProject.exe (HonorKitchen Demo — в установщике)
- **Жанр:** однопользовательский хоррор, процедурная кухня / побег
- **Цель показа:** демонстрация прогресса после v0.1-demo: генерация, геймплей, известные ограничения

## Стек

- Unreal Engine **5.3**
- C++ + Blueprints
- Inno Setup 6 — установщик (`Tools/InnoSetup_MyProject_Demo.iss`)

## Что сделано с прошлого показа (кратко)

- Процедурная генерация кухни: устойчивость, метрики, детерминированнее RNG
- AI: рефакторинг контроллера врага, стабильность состояний, locomotion Nav/Direct, watchdog
- Инвентарь: стаки, хотбар, тест-выдача для отладки
- Документация: 14-дневный план, регресс-чеклист, журнал багов, инструкция установщика

## Что осталось (для честного слайда «риски»)

- Довести преследование врагов в **Chase** (замирание на дистанции; **Melee** стабильнее)
- **Модели:** враги и окружение карты (замена прототипных мешей)
- Финальный **Shipping** + установщик на каждую дату показа

## Итог для куратора одной фразой

Игра демонстрирует цикл и процедурную карту; визуал и поведение врагов на дистанции — в работе, план зафиксирован в репозитории.
