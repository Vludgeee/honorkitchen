## Слайд 4. Что осталось сделать (честно, без приукрашивания)

**Обязательно для следующего показа:**

1. **Враги (геймплей)** — довести преследование в режиме **Chase** (замирание на дистанции; в **Melee** поведение лучше). Задачи: BUG-019, BUG-011 в `BUGS.md`.
2. **Визуал** — поставить **модели врагам** (томатозавр, каравайчик, при необходимости вилохвост) и **улучшить окружение карты** (мебель/пропсы вместо чистых примитивов где это видно куратору).
3. **Установка** — упакованный **Shipping** билд + установщик Inno Setup (см. `Tools/InnoSetup_MyProject_Demo.iss` и `Docs/INSTALLER_BUILD.md`).

**Желательно (если успеешь):**

- Короткое видео 2–3 мин с фиксированным сценарием
- Один слайд «известные ограничения»: Win10/11, VC++ Redist

## Слайд 5. Демо-сценарий на 3–5 минут (рекомендуется зафиксировать)

1. Запуск из установщика или папки `WindowsNoEditor`.
2. Новая игра → 30–60 с объяснения цели (собрать батарейки, портал).
3. Показать генерацию (один seed или «как есть»).
4. Контакт с врагом (честно: если Chase подводит — показать ближний бой / крошку / крик каравайчика).
5. Выход в меню без зависания.
