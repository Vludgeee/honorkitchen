HonorKitchen / MyProject — демо-сборка
======================================

Запуск
------
1. Установите Microsoft Visual C++ Redistributable x64 (2015-2022), если игра не стартует:
   https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist
2. Запустите MyProject.exe (или ярлык после установки из установщика).

Платформа
---------
Сборка Win64, Unreal Engine 5.3. Рекомендуется Windows 10 или 11 (64-bit).
На Windows 8/8.1 запуск не гарантируется из-за требований движка.

Если не запускается
-------------------
- Обновите видеодрайвер.
- Установите VC++ Redistributable x64.
- Запустите от имени обычного пользователя из короткого пути (например C:\Games\...).

Управление (типичная раскладка First Person)
---------------------------------------------
- WASD — движение
- Мышь — обзор
- Пробел — прыжок
- Бросок крошки / действие — см. назначение в проекте (Enhanced Input: IMC_Default)
- Цифры 1–5 или колесо мыши — слоты хотбара (если включено в сборке)
- Esc — пауза / меню (если настроено в билде)

Перед показом куратору проверь раскладку в редакторе: Content/FirstPerson/Input/IMC_Default.
