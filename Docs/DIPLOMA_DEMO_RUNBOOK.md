## Критично про Windows 8 / 10 / 11

Проект: **Unreal Engine 5.3** (`MyProject.uproject`).

- **Официально Epic ориентируется на Windows 10 x64 и новее.** Сборка под Win64 из редактора рассчитана на **Win10/11**.
- **Windows 8 / 8.1** с UE5 часто **не гарантируются**: могут отсутствовать нужные API/рантаймы, антивирус/драйверы старые.
- **Что сделать для комиссии:**  
  1. Иметь на флешке **упакованный билд** (Shipping, Win64) + **VC++ Redistributable** (см. ниже).  
  2. Иметь **запасной ноут/ПК на Win10/11** для показа, если на Win8 не стартует.  
  3. В устном вступлении честно: *«Целевая платформа Win10/11; на Win8 возможны ограничения из‑за требований UE5»*.

## Что класть на флешку (приоритет)

1. **Папка упакованной игры** (не обязательно весь `.sln`/исходники, если показывают только геймплей):  
   `WindowsNoEditor` / `Windows` из **File → Package Project → Windows (64-bit)**.  
2. **`README_DEMO.txt`** — управление, что запускать (`MyProject.exe` или имя твоего exe).  
3. **`VC_redist.x64.exe`** — [Microsoft Visual C++ Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist) (x64), та же мажорная версия, что у твоей сборки (часто 2015–2022 unified).  
4. (Опционально) **Установщик** `.exe`, собранный из Inno Setup — см. `Tools/InnoSetup_MyProject_Demo.iss` и **`Docs/INSTALLER_BUILD.md`**.  
5. **Презентация для куратора (колледж):** `Docs/CURATOR_COLLEGE_PRESENTATION.md`.  
6. **Резерв:** короткое **видео** 2–3 мин (если живой запуск вдруг не взлетит).

## Минимальный чек перед выходом из дома (15 минут)

- [ ] Запуск **с флешки** на твоей машине: двойной клик по exe из **копии** с флешки.  
- [ ] Полный цикл: старт → 1–2 мин геймплей → выход без зависания.  
- [ ] Разрешение окна приемлемое; Esc/меню не ломают ввод.  
- [ ] На флешке есть **redist** и **текст** «если не запускается — поставить VC++ x64».

## Чек‑лист работ к защите (после Сибинтека), по важности

### Неделя 1 — комиссия не ломается о технику
1. Главное меню: Новая игра, Выход; экран/текст «Управление».  
2. Цикл: меню → раунд → конец → снова меню **без** обязательного перезапуска exe.  
3. Одна строка контекста (где игрок / что искать) в начале.  
4. `CONTROLS.txt` рядом с билдом.  
5. Зафиксировать **один демо‑сценарий** (один режим/сложность/seed), чтобы RNG не подставил на защите.

### Неделя 2 — враги не выглядят «сломанными»
6. Минимальный аудио: шаги, враг, урон, подбор ключевого предмета.  
7. Каравайчики: проход против застреваний (навигация/коллизии/радиусы).  
8. Читаемость угрозы (силуэт/HUD в радиусе).  
9. Одно ограничение на «слишком лёгкий побег» для демо (aggro/скорость/зона).

### Неделя 3 — «результат», а не прототип в голове
10. 5 скриншотов из **Shipping**.  
11. Видео 2–3 мин фиксированного сценария.  
12. Текст защиты на 1 стр.: цель, архитектура (генератор, режимы, враги), твой вклад, ограничения.

### Финальная неделя до 6 июня
13. Только стабильность + **Shipping** на «слабом» ПК если есть.  
14. Короткий `BUGS.md` / известные ограничения.

**После диплома (не блокер):** полный seed/RNG, сохранения, маркетинг, полный аудит лицензий ассетов.

## Само‑QA без тестеров (регресс 10–15 мин после кодинга)

- Новая игра с нуля до победы **или** явного конца.  
- Один раз **Alt+F4** → снова запуск.  
- Два разрешения: **1920×1080** и **1366×768** если доступно.  
- Проверка с **копии на флешке**, не только с SSD.

## Твои ответы по тесту (краткая сводка для себя)

Сильные стороны: цель понятна, много пунктов стабильности/генерации ок, базовый UX частично закрыт.  
Риски: нет меню, нет аудио, враги/читаемость/скука повторов, нет зафиксированного демо‑пакета и артефактов защиты, усталость.

## Срочно сейчас (если не спал)

1. **Упаковать Shipping** один раз, проверить запуск.

3. **Поспать хотя бы 1–2 цикла сна** до поездки, если есть окно — иначе показ страдает больше, чем от недостающей фичи.
